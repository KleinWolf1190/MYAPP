## 3. 每一類資料需要確認

- 資料來源

- 修改時間

## 4. 儲存方案候選

目前不先鎖定技術。

### A. JSON / 純文字資料
適合：
- 小型資料
- 設定
- 可讀的匯入 / 匯出格式

### B. SQLite / 本機資料庫
適合：
- 大量資料
- 搜尋
- 篩選
- 關聯資料

### C. 雲端 API
適合：
- 跨裝置
- 帳號
- 同步
- 多人協作

最終方案依需求決定。

---

## 5. 資料安全

不得把以下資料直接提交到 Git：
- API Key
- Access Token
- 密碼
- 私密設定
- 使用者個資

需要秘密管理時，應使用環境設定或平台提供的安全儲存機制。
