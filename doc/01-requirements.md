## 2. 功能候選池

以下只是需求討論的分類框架，不代表全部都必須實作。

### A. 首頁 / Dashboard
- 核心資訊摘要
- 最近使用項目
- 快速操作
- 系統狀態

### B. 主要功能區
- APP 的核心工作流程
- 建立 / 編輯 / 刪除主要資料
- 搜尋、篩選、排序
- 詳細檢視

### C. 資料管理
- 本機儲存
- 匯入資料
- 匯出資料
- 備份與還原
- 資料版本

### D. 使用者設定
- 外觀設定
- 語言
- 操作方式
- 通知
- 資料管理

### E. 輔助功能
- 新手引導
- 說明
- 錯誤提示
- 日誌 / 診斷資訊

### F. 未來擴充
- 帳號系統
- 雲端同步
- API
- 多人協作
- AI 功能

上述項目應依實際 APP 目的重新刪減。

## 3. MVP 建議格式

第一版只保留能完成核心工作流程的功能。

| 功能 | 說明 | 優先級 | 第一版 |
|---|---|---:|---|
| 核心流程 | 待討論 | P0 | 待定 |
| 主要資料操作 | 待討論 | P0 | 待定 |
| 首頁 | 待討論 | P1 | 待定 |
| 搜尋 / 篩選 | 待討論 | P1 | 待定 |
| 設定 | 待討論 | P2 | 待定 |
| 匯入 / 匯出 | 待討論 | P2 | 待定 |
| 雲端同步 | 待討論 | P3 | 否 |

優先級定義：
- **P0**：沒有它就無法使用核心功能
- **P1**：核心體驗需要
- **P2**：方便性 / 完整性功能
- **P3**：未來擴充
